# Old Hunter 74 — downloads

Este repositório guarda **apenas os instaladores** (releases) do Old Hunter 74.
O código-fonte não fica aqui.

- **Baixar:** abra a [última release](../../releases/latest) e baixe o arquivo `.zip`.
- **Instalar:** extraia o zip numa pasta e abra `OldenHunter.exe`. Na primeira vez o
  programa mostra o ID do seu PC — envie para o suporte para receber a chave de licença.
- **Atualizar:** o programa avisa sozinho quando sai versão nova e atualiza sem apagar
  as suas configurações.

> Muitos servidores proíbem bots e podem banir a conta. Confira as regras do servidor
> onde você joga — o risco de uso é do jogador. Produto independente, sem ligação com
> servidores ou empresas de jogos.
